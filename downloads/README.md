# downloads

Third-party models (one folder per item). Each folder keeps the original
files as downloaded; add a `README.md` inside with the source URL and license
so the origin stays findable.

- Print-ready files stay in `print/`, editable sources in `src/` (for items
  that were modified, e.g. `hazszam`).
- `links.md` collects Printables/Thingiverse URLs for wall-decor, mandalas,
  and house-number reference designs.
