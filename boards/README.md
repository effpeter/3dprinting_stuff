# boards

Reference material for printer hardware: manuals (PDF), wiring/pin diagrams,
and STEP part models. Not projects I design - just the datasheets to have
on hand.

- `BTT_SKR_MINI_E3_V2.0/` - board 3D model, pinout, manual
- `BIQU_MicroProbe_V2/` - mockup + manual
- `Ender-3/` - full assembly STEP parts (screws, fans, belts, frames)
